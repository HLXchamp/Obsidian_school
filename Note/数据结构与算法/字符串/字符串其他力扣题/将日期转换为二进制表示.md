这道题主要有两个关键点：**字符串转化为数字**，**数字转化成二进制**。

#### 字符串转化为数字

用 **LocalDate** 对象：

```java
public String convertDateToBinary(String date) {
    // 解析日期字符串为 LocalDate 对象
    LocalDate localDate = LocalDate.parse(date);
    int year = localDate.getYear();
    int month = localDate.getMonthValue(); 
    int day = localDate.getDayOfMonth();
}
```

字符串切割： 

```java
public String convertDateToBinary(String date) {
    Integer year = Integer.parseInt(date.substring(0,4));
    Integer month = Integer.parseInt(date.substring(5,7));
    Integer day = Integer.parseInt(date.substring(8,10));
}
```

#### 数字转化成二进制

手动计算余数的方式，将十进制数逐位转换为二进制：

```java
public String convert(Integer nums){
    StringBuilder temp = new StringBuilder();
    while (nums > 0) {
        temp.insert(0, nums % 2); // 取余数，插入到字符串前
        nums /= 2; 
    }       
    return temp.toString();
} 
```

内置方法 `Integer.toBinaryString()`：

```java
public class DecimalToBinary {
    public static void main(String[] args) {
        int decimal = 42; // 十进制数
        // 转换为二进制
        String binary = Integer.toBinaryString(decimal);
        System.out.println("二进制: " + binary);
    }
}
```

#### 整体代码

LocalDate + 手动计算余数：

```java
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;

class Solution {
    public String convertDateToBinary(String date) {
        //解析日期字符串为 LocalDate 对象
        LocalDate localDate = LocalDate.parse(date);
        int year = localDate.getYear();
        int month = localDate.getMonthValue(); 
        int day = localDate.getDayOfMonth();

        return convert(year) + '-' + convert(month) + '-' + convert(day);
    }

    public String convert(Integer nums){
        StringBuilder temp = new StringBuilder();
        while (nums > 0) {
            temp.insert(0, nums % 2); // 取余数，插入到字符串前
            nums /= 2; 
        }       
        return temp.toString();
    } 
}
```

简化版本：

```java
class Solution {
    public String convertDateToBinary(String date) {
        return Integer.toBinaryString(Integer.parseInt(date.substring(0,4)))
        + "-" + Integer.toBinaryString(Integer.parseInt(date.substring(5,7)))
        + "-" + Integer.toBinaryString(Integer.parseInt(date.substring(8,10)));
    }
}
```
