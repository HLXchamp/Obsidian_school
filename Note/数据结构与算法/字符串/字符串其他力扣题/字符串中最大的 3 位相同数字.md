##### 解法一

遍历字符串查找有没有重复数字组成的子字符串，有的话再转化成数字比较。

```java
class Solution {
    public String largestGoodInteger(String num) {
        String max = "";
        int temp = -1;
        for(int i = 2; i < num.length(); i++){
            if(num.charAt(i) == num.charAt(i - 1) && num.charAt(i - 1) == num.charAt(i - 2)){
                String sub = num.substring(i - 2, i + 1);
                if(Integer.parseInt(sub) > temp){
                    temp = Integer.parseInt(sub);
                    max = sub;
                }
            }
        }
        return max;
    }
}
```

##### 解法二

三个连续的最大的数一定是999，没有的话就是888，以此类推遍历字符串中是否包含逐渐减小的连续数。

`repeat(3)`的用法：将字符重复三遍。

```java
class Solution {
    public String largestGoodInteger(String num) {
        for (char d = '9'; d >= '0'; d--) {
            String s = String.valueOf(d).repeat(3);
            if (num.contains(s)) {
                return s;
            }
        }
        return "";
    }
}
```
