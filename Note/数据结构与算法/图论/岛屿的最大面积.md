这道题就是怎么计算每个岛屿的数量的问题，搞清楚遍历的一些细节就好。

### DFS

```java
class Solution {
    int[][] hash = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
    int max = 0;

    public int maxAreaOfIsland(int[][] grid) {
        int col = grid.length;
        int row = grid[0].length;
        int res = 0;
        boolean[][] visited = new boolean[col][row];
        for (int i = 0; i < col; i++) {
            for (int j = 0; j < row; j++) {
                if(grid[i][j] == 1 && !visited[i][j]){
                    visited[i][j] = true;
                    max++; // 不要漏了第一个节点
                    dfs(grid, i, j, visited);
                    res = Math.max(res, max);
                    max = 0;
                }
            }
        }
        return res;
    }

    public void dfs(int[][] grid, int x, int y, boolean[][] visited){
        int col = grid.length;
        int row = grid[0].length;
        for (int[] temp : hash){
            int nx = x + temp[0];
            int ny = y + temp[1];
            if(nx < 0 || ny < 0 || nx >= col || ny >= row || visited[nx][ny] || grid[nx][ny] == 0){
                continue;
            } else {
                visited[nx][ny] = true;
                max++; // max的计数应该在进入dfs时立即增加，而不是在递归调用后增加
                dfs(grid, nx, ny, visited);
            }
        }
    }
}
```


### BFS


```java
class Solution {
    int[][] hash = {{-1, 0}, {1, 0}, {0, 1}, {0, -1}}; // 上下左右
    int max = 0;
    
    public int maxAreaOfIsland(int[][] grid) {
        int col = grid.length;     // 行
        int row = grid[0].length;  // 列
        boolean[][] visited = new boolean[col][row];
        int res = 0;
        for (int i = 0; i < col; i++) {
            for (int j = 0; j < row; j++) {
                if(grid[i][j] == 1 && !visited[i][j]){
                    bfs(grid, i, j, visited);
                    res = Math.max(res, max); // 每次完整处理一个岛屿后进行++
                    max = 0;
                }
            }
        }
        return res;
    }

    public void bfs(int[][] grid, int x, int y, boolean[][] visited) {
        int col = grid.length;     // 行
        int row = grid[0].length;  // 列
        Queue<int[]> queue = new ArrayDeque<>(); // 队列保存数组下标
        queue.add(new int[]{x, y});
        max++;
        visited[x][y] = true; 
        while (!queue.isEmpty()){  
            int[] point = queue.poll(); 
            for(int[] temp : hash){
                int nx = point[0] + temp[0];
                int ny = point[1] + temp[1];
                if(nx < 0 || ny < 0 || nx >= col || ny >= row || visited[nx][ny] || grid[nx][ny] == 0){
                    continue;
                } else {
                    queue.add(new int[]{nx, ny});
                    max++;
                    visited[nx][ny] = true;
                }
            }
        }
    }
}
```
