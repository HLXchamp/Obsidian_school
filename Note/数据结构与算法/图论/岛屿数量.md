这道题题目是 **DFS**，**BFS**，**并查集** 的基础题目。

### 本题思路

遇到一个没有遍历过的节点陆地，计数器就加一，然后把该节点陆地所能遍历到的陆地都**标记**上。在遇到标记过的陆地节点和海洋节点的时候直接跳过。 这样计数器就是最终岛屿的数量。

那么如何把节点陆地所能遍历到的陆地都标记上呢，就可以使用 DFS，BFS或者并查集。

### 深度优先搜索

和思路完全一致，注意跳过时的条件：在遇到标记过的陆地节点和海洋节点的时候直接跳过。

注意事项：

- 要新建一个`boolean`数组来统计节点是否被遍历过，之后`dfs`时也要传这个数组；
- 要新建一个哈希数组存储上下左右的节点；
- 注意跳过时的条件！


```java
class Solution {
    int[][] hash = {{-1, 0}, {1, 0}, {0, 1}, {0, -1}}; // 上下左右
    int res = 0;

    public int numIslands(char[][] grid) {
        int col = grid.length;     // 行
        int row = grid[0].length;  // 列
        boolean[][] visited = new boolean[col][row]; // 统计是否被遍历过
        int res = 0;
        for (int i = 0; i < col; i++) {
            for (int j = 0; j < row; j++) {
                if(grid[i][j] == '1' && !visited[i][j]){ // grid是字符数组
                    res++;
                    visited[i][j] = true;
                    dfs(grid, i, j, visited);
                }
            }
        }
        return res;
    }

    public void dfs(char[][] grid, int x, int y, boolean[][] visited) {
        int col = grid.length;     
        int row = grid[0].length;
        for (int[] temp : hash) {
            int nx = x + temp[0];
            int ny = y + temp[1];
            if (nx >= 0 && nx < col && ny >= 0 && ny < row) {
                if(grid[nx][ny] == '1' && !visited[nx][ny]){ // 避免重复访问
                    visited[nx][ny] = true;
                    dfs(grid, nx, ny, visited);
                } 
            }
        }
    }
}
```

### 广度优先搜索

**只要加入队列就代表走过，就需要标记，而不是从队列拿出来的时候再去标记走过**。如果从队列拿出节点，再去标记这个节点走过，就会发生下图所示的结果，会导致很多节点重复加入队列。

![图二](https://code-thinking-1253855093.file.myqcloud.com/pics/20220727100846.png)

在广度优先搜索 (BFS) 中，通常不会使用递归调用 bfs 函数。BFS 是通过**队列**实现的**迭代算法**，而不是递归。递归通常用于深度优先搜索 (DFS)。

注意事项：

- 要熟悉队列的使用，加入节点时应该是`queue.add(new int[]{x, y});`
- 每次完整处理一个岛屿后进行`res++`。

```java
 class Solution {
    int[][] hash = {{-1, 0}, {1, 0}, {0, 1}, {0, -1}}; // 上下左右

    public int numIslands(char[][] grid) {
        int col = grid.length;     // 行
        int row = grid[0].length;  // 列
        boolean[][] visited = new boolean[col][row];
        int res = 0;
        for (int i = 0; i < col; i++) {
            for (int j = 0; j < row; j++) {
                if(grid[i][j] == '1' && !visited[i][j]){
                    bfs(grid, i, j, visited);
                    res++; // 每次完整处理一个岛屿后进行++
                }
            }
        }
        return res;
    }

    public void bfs(char[][] grid, int x, int y, boolean[][] visited) {
        int col = grid.length;     // 行
        int row = grid[0].length;  // 列
        Queue<int[]> queue = new ArrayDeque<>(); // 队列保存数组下标
        queue.add(new int[]{x, y});
        visited[x][y] = true;
        while (!queue.isEmpty()){
            int[] point = queue.poll();
            for(int[] temp : hash){
                int nx = point[0] + temp[0];
                int ny = point[1] + temp[1];
                if(nx < 0 || ny < 0 || nx >= col || ny >= row || visited[nx][ny] || grid[nx][ny] == '0'){
                    continue;
                } else {
                    queue.add(new int[]{nx, ny});
                    visited[nx][ny] = true;
                }
            }
        }
    }
}
```
