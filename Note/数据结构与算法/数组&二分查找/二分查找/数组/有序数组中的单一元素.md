#### 方法一：暴力解法

相同元素都是一起出现的，说明单独元素在数组中的元素位置一定是奇数，就两个两个的查，相同的话换下两个，不同的话就是两个中前面的那个。

```java
class Solution {
    public int singleNonDuplicate(int[] nums) {
        if(nums.length < 2){
            return nums[0];
        }
        int res = nums[0];
        int i = 0;
        while (i < nums.length - 1) {
            if(nums[i + 1] != nums[i]){
                return nums[i];
            } else {
                i += 2;
                res = nums[i];
            }
        }
        return res;
    }
}
```

#### 方法二：二分查找

其实看到 时间复杂度 要求为 `O(logN)`，就一定要先想到用二分查找！！！只不过这道题的二分查找要有点技巧：

**按位异或（XOR）运算符** `^` ：`middle ^ 1` 的目的是让索引 `middle` 跳到与当前索引成对的那个位置。例如，在一个排序数组中，若每个元素都出现两次，除了一个元素只出现一次，这个操作会帮助找到每对元素的起始或结束位置。具体来说：

- 如果 `middle` 是偶数，`middle ^ 1` 会返回 `middle + 1`。
- 如果 `middle` 是奇数，`middle ^ 1` 会返回 `middle - 1`。

```java
输入: nums = [1,1,2,3,3,4,4,8,8]
输出: 2

输入: nums = [3,3,7,7,10,11,11]
输出: 10
```

对于`nums[middle] == nums[middle ^ 1]`：

- 如果相等，则说明当前 `middle` 在一个成对元素的左侧或右侧，说明单独元素在 `middle` 右边，因此更新 `low = middle + 1`。
- 如果不相等，则说明 `middle` 落在不成对的区域，因此更新 `high = middle`。

```java
class Solution {
    public int singleNonDuplicate(int[] nums) {
        int length = nums.length;
        if(length < 2){
            return nums[0];
        }
        int low = 0;
        int high = length - 1;
        while(low < high){
            int middle = (high - low) / 2 + low;
            if(nums[middle] == nums[middle ^ 1]) {
                low = middle + 1;
            } else {
                high = middle;
            }
        }
        return nums[low];
    }
}
```
