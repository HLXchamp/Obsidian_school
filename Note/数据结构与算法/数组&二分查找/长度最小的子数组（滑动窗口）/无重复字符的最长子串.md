一定要看清题意！这里说的是**无重复字符**，不是无重复字母！而且提示里说了还有数字，符号和空格。

- 使用了一个**哈希数组**`temp`来记录字符是否重复，因为这里是字符，所以用的长度为**128**，**ASCLL为0的字符是'\0'**，所以就减它；
- 记录哈希数组时应该从`end`开始加，`end`从0开始保证所有字符都能加进去；
- 如果重复的话（`temp`数组对应的值>1）应该最左边的数组值减一，然后向右边移一位！

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int length = s.length();
        if(length <= 1){
            return length;
        }
        int[] temp = new int[128];
        int res = 0;
        int start = 0;
        for(int end = 0; end < length; end++){
            //遍历一个end就加一个
            temp[s.charAt(end) - '\0']++;
            while(temp[s.charAt(end) - '\0'] > 1){
                //重复了的话就从左边start减，然后start往右边移一位
                temp[s.charAt(start) - '\0']--;
                start++;
            }
            res = Math.max(res, end - start + 1);
        } 
        return res;
    }
}
```

当然也可以不用哈希数组，可以用**哈希集合** `set` 来记录当前窗口中的字符：

```java
public class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 使用滑动窗口
        HashSet<Character> set = new HashSet<>();
        int maxLength = 0;
        int start = 0;
        
        for (int end = 0; end < s.length(); end++) {
            // 如果发现重复字符，从窗口中移除左侧字符
            while (set.contains(s.charAt(end))) {
                set.remove(s.charAt(start));
                start++;
            }
            // 将当前字符加入窗口
            set.add(s.charAt(end));
            // 更新最大长度
            maxLength = Math.max(maxLength, end - start + 1);
        }
        
        return maxLength;
    }
}
```
