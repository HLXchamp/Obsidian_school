### 方法一：暴力解法

首先记录车的位置，之后遇到卒或者象就标记`visited`数组，然后对于和车在同一行或同一列的卒，判断直接有没有被标记，没有的话`res++`。

缺点：代码有点繁琐

```java
class Solution {
    public int numRookCaptures(char[][] board) {
        int car_x = 0;
        int car_y = 0;
        int res = 0;
        boolean[][] visited = new boolean[8][8];
        List<List<Integer>> people = new ArrayList<>();
        for(int i = 0; i < 8; i++){
            for(int j = 0; j < 8; j++){
                if(board[i][j] == 'R'){
                    car_x = i;
                    car_y = j;
                }
                if(board[i][j] == 'p'){
                    people.add(Arrays.asList(i, j));
                    visited[i][j] = true;
                }
                if(board[i][j] == 'B'){
                    visited[i][j] = true;
                }
            }
        } 
        for(List<Integer> temp : people){
            if(temp.get(0) == car_x){
                if(car_y > temp.get(1)){
                    boolean found = false; 
                    for(int i = temp.get(1) + 1; i < car_y; i++){
                        if(visited[car_x][i]){
                            found = true;
                            break;
                        }
                    }
                    if(!found){
                        res++;
                    }
                } else{
                    boolean found = false; 
                    for(int i = car_y + 1; i < temp.get(1); i++){
                        if(visited[car_x][i]){
                            found = true;
                            break;
                        }
                    }
                    if(!found){
                        res++;
                    }
                }
            }
            if(temp.get(1) == car_y){
                if(car_x > temp.get(0)){
                    boolean found = false; 
                    for(int i = temp.get(0) + 1; i < car_x; i++){
                        if(visited[i][car_y]){
                            found = true;
                            break;
                        }
                    }
                    if(!found){
                        res++;
                    }
                } else{
                    boolean found = false; 
                    for(int i = car_x + 1; i < temp.get(0); i++){
                        if(visited[i][car_y]){
                            found = true;
                            break;
                        }
                    }
                    if(!found){
                        res++;
                    }
                }
            }
        }
        return res;
    }
}
```


方法二：

使用 `dx` 和 `dy` 数组表示上下左右四个方向，简化搜索逻辑。

注：每一行/列最多只能找到一个卒，所以找到了就break！

```java
class Solution {
    public int numRookCaptures(char[][] board) {
        int car_x = -1;
        int car_y = -1;
        int res = 0;
        for(int i = 0; i < 8; i++){
            for(int j = 0; j < 8; j++){
                if(board[i][j] == 'R'){
                    car_x = i;
                    car_y = j;
                    break;
                }
            }
            if(car_x != -1){
                break;
            }
        } 
        int[] dx = {1, -1, 0, 0};
        int[] dy = {0, 0, 1, -1};
        for(int i = 0; i < 4; i++){
            int x = car_x;
            int y = car_y;
            while(true){
                x += dx[i];
                y += dy[i];
                if(x >= 8 || x < 0 || y >= 8 || y < 0){
                    break;
                }
                if(board[x][y] == 'B'){
                    break;
                }
                if(board[x][y] == 'p'){
                    res++;
                    break; // 每一行/列最多只能找到一个卒，所以找到了就break
                }
            }
        }
        return res;
    }
}
```
