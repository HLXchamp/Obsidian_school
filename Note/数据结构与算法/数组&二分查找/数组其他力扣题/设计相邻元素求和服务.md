#### 方法一：暴力解法

先找到对应元素在数组中位置，再分别判断自己的上下左右和对角线元素是否合法，然后再进行求和：

```java
class NeighborSum {
    private int[][] nums;
    private int n;

    public NeighborSum(int[][] grid) {
        this.nums = grid;
        this.n = grid.length;
    }
    
    public int adjacentSum(int value) {
        int x = locate(value)[0];
        int y = locate(value)[1];
        int num1 = y == 0 ? 0 : nums[x][y - 1];
        int num2 = y == n - 1 ? 0 : nums[x][y + 1];
        int num3 = x == 0 ? 0 : nums[x - 1][y];
        int num4 = x == n - 1 ? 0 : nums[x + 1][y];
        return num1 + num2 + num3 + num4; 
    }
    
    public int diagonalSum(int value) {
        int x = locate(value)[0];
        int y = locate(value)[1];
        int num1 = (x > 0 && y > 0) ? nums[x - 1][y - 1] : 0;
        int num2 = (x > 0 && y < n - 1) ? nums[x - 1][y + 1] : 0;
        int num3 = (x < n - 1 && y > 0) ? nums[x + 1][y - 1] : 0;
        int num4 = (x < n - 1 && y < n - 1) ? nums[x + 1][y + 1] : 0;
        return num1 + num2 + num3 + num4; 
    }

    public int[] locate(int value){
        int[] res = new int[2];
        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                if(nums[i][j] == value){
                    res[0] = i;
                    res[1] = j;
                }
            }
        }
        return res;
    }
}

/**
 * Your NeighborSum object will be instantiated and called as such:
 * NeighborSum obj = new NeighborSum(grid);
 * int param_1 = obj.adjacentSum(value);
 * int param_2 = obj.diagonalSum(value);
 */
```

##### 复杂度分析

**时间复杂度**：初始化需要的时间为 O(n<sup>2</sup>)，每一次查询操作需要的时间也为 O(n<sup>2</sup>)。

**空间复杂度**：整个类需要的空间为 O(n<sup>2</sup>)，其中包含 O(n<sup>2</sup>) 的哈希表空间或 O(n<sup>2</sup>)/O(1) 的二维数组 grid 的副本的空间。每一次查询操作需要的空间为 O(1) 。
