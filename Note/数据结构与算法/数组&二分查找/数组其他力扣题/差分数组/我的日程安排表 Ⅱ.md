#### 方法一：直接遍历

- 这道题对于`calendar`就是要把所有日程区间加进去了，以便求重叠区间；
- 再新建一个集合`overlap`，用来**存储重叠一次的区间**，然后每次安排日程就看有没有和`overlap`中的每一个区间重合，如果有的话就说明是三重预定，返回`false`。

```java
class MyCalendarTwo {

    List<int[]> calendar;
    List<int[]> overlap;

    public MyCalendarTwo() {
        this.calendar = new ArrayList<>();
        this.overlap = new ArrayList<>();
    }

    public boolean book(int startTime, int endTime) {
        if(calendar.isEmpty()){
            calendar.add(new int[]{startTime, endTime});
            return true;
        }
        for (int[] temp : overlap){
            if(startTime < temp[1] && endTime > temp[0]){
                return false;
            }
        }
        for (int[] temp : calendar){
            if(startTime < temp[1] && endTime > temp[0]){
                int begin = Math.max(startTime, temp[0]);
                int end = Math.min(endTime, temp[1]);
                overlap.add(new int[]{begin, end});
            }
        }
        calendar.add(new int[]{startTime, endTime});
        return true;
    }
}

/**
 * Your MyCalendarTwo object will be instantiated and called as such:
 * MyCalendarTwo obj = new MyCalendarTwo();
 * boolean param_1 = obj.book(startTime,endTime);
 */
```
