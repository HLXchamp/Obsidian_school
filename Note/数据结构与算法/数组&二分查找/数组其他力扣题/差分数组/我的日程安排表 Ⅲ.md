#### 方法一：**扫描线算法** 

扫描线的**核心思想**是：

- 将每个区间的起点作为一个“**事件**”，记为+1，将终点作为另一个“事件”，记为-1。
- 扫描这些事件的时间点，统计当前重叠区间的数量，并维护最大重叠次数。

 `events` 使用 `TreeMap` 来存储每个关键时间点的增减事件，按照 **Key 的自然顺序（时间顺序）自动排序**：
 
- **Key**：表示某个具体的时间点（开始或结束时间）。
- **Value**：表示在该时间点的事件数量变化。
    - `+1` 表示在该时间点有一个新的日程开始。
    - `-1` 表示在该时间点有一个日程结束。


```java
class MyCalendarThree {

    private TreeMap<Integer, Integer> events;

    public MyCalendarThree() {
        this.events = new TreeMap<>();
    }

    public int book(int startTime, int endTime) {
        events.put(startTime, events.getOrDefault(startTime, 0) + 1);
        events.put(endTime, events.getOrDefault(endTime, 0) - 1);

        int maxCount = 0;
        int count = 0;
        for(int temp : events.values()){
            count += temp;
            maxCount = Math.max(maxCount, count);
        }

        return maxCount;
    }
}
```

##### **这个方法与差分数组的思想非常相似！**

##### **差分数组的思想**

差分数组的基本思想是通过记录区间起点和终点的变化量，快速计算出每个位置的**累积值**。例如，在处理一维数组时，我们用一个辅助数组记录“变化量”，这样通过一次遍历累加这些变化量，就能得到目标数组。
