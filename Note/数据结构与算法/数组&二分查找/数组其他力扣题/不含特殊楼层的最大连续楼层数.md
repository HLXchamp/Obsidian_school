在`special`数组中计算连续楼层要再减一：`special[i] - special[i - 1] - 1`。

```java
class Solution {
    public int maxConsecutive(int bottom, int top, int[] special) {
        Arrays.sort(special);
        int length = special.length;
        int max = Math.max(special[0] - bottom, top - special[length - 1]);
        for(int i = 1; i < length; i++){
            max = Math.max(max, special[i] - special[i - 1] - 1);
        }
        return max;
    }
}
```
