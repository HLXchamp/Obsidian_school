思路：用ACSLL码

注：英文大写字母与小写字母的ACSLL差值是 **32**！

```java
class Solution {
    public int countKeyChanges(String s) {
        int res = 0;
        for (int i = 1; i < s.length(); i++) {
            if(s.charAt(i) == s.charAt(i - 1) || s.charAt(i) - 'a' == s.charAt(i - 1) - 'a' + 32 || s.charAt(i) - 'a' == s.charAt(i - 1) - 'a' - 32){
                continue;
            } else {
                res++;
            }
        }
        return res;
    }
}
```

也可以用 **按位与操作**：

当两个相应的二进制位都是1时，结果为1；否则为0。

- 例如：`0101 & 0111 = 0101`

通过 `& 31`，大写和小写字母都被映射到相同的值范围（1 到 26），这意味着它们在字母表中的位置相同。

```java
class Solution {
    public int countKeyChanges(String s) {
        int res = 0;
        for(int i = 0; i < s.length() - 1; i++){
            if((s.charAt(i) & 31) != (s.charAt(i + 1) & 31)) res++;
        }
        return res;
    }
}
```
